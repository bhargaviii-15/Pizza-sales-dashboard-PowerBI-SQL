# 🍕 Pizza Sales Dashboard

## 📊 Project Overview
The **Pizza Sales Dashboard** is a data analytics project that provides powerful insights into pizza sales performance.  
It visualizes key metrics like revenue, orders, top-selling pizzas, and sales trends — enabling better business decisions through data.

---

## 🎯 Objectives
- Analyze pizza sales data to uncover performance trends.  
- Visualize key metrics such as total revenue, order volume, and average order value.  
- Identify top-performing pizzas by revenue and quantity sold.  
- Understand customer preferences by pizza category and size.  
- Assist stakeholders in making informed marketing and inventory decisions.  

---

## 🧠 Key Insights
- 💰 **Total Revenue:** Displays total sales generated from all orders.  
- 🧾 **Total Orders:** Tracks the total number of orders placed.  
- 📈 **Average Order Value (AOV):** Shows the average revenue per order.  
- 🍕 **Top-Selling Pizzas:** Highlights the best-selling pizzas based on revenue and quantity.  
- 🧩 **Sales by Category & Size:** Visualizes performance across pizza types (Classic, Supreme, Veggie, etc.) and sizes (S, M, L, XL).  
- 📅 **Daily & Monthly Trends:** Reveals peak sales days and monthly performance trends.

## 📈 Dashboard Features
- Interactive filters for **date range**, **pizza category**, and **size**.  
- KPI cards showing **Revenue**, **Orders**, and **Average Order Value**.  
- Visuals for **Revenue by Category**, **Top 5 Pizzas**, and **Order Trends Over Time**.  
- Drill-through and hover-over tooltips for deeper insights.  
- Clean, user-friendly layout optimized for presentation.
